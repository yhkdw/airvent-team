# AirVent Homepage + Dashboard (v1.4.0)

## Run
- npm install
- npm run dev

## Build
- npm run build
- npm run preview

## Notes
- This app is a single-file React UI (src/App.tsx) designed for demo/PoC.
- CSV export supports CRLF/LF modes (Excel-friendly default: CRLF).
- Debug API is exposed on `window.__airvent` (see code).
