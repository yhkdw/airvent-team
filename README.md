# AirVent Homepage + Dashboard (React) — v1.3.4

단일 파일 React 앱(Homepage + Dashboard)입니다.

## Dashboard Modes
- Public Explorer: 공개 익스플로러 (노드 지도 + 상태 + 리스트 + 선택 상세)
- Operations Dashboard: 운영 대시보드 (멀티사이트 KPI/알림/CSV Export)
- Personal Dashboard: 개인 대시보드 (내 디바이스/내 리워드/내 CSV)

## Console Debug API
브라우저 콘솔:
- __airvent.runSelfTests()
- __airvent.openPublicExplorer()
- __airvent.openOpsDashboard()
- __airvent.openPersonalDashboard()
- __airvent.connectWallet() / __airvent.disconnectWallet()
- __airvent.setCsvNewline("CRLF") / __airvent.setCsvNewline("LF")
